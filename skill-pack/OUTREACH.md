# Candidate Outreach & Greeting

Use this workflow for generating multi-channel candidate outreach messages (Boss直聘打招呼、脉脉/校友内推私信、LinkedIn 外联、直投邮件).

## Overview

根据目标公司、岗位 JD 与候选人 `profile_store.yaml` 事实库，生成高转化率的外联沟通文案。不同求职渠道对字数、阅读节奏与切入点的要求截然不同：

| 渠道类型 | 黄金字数 | 核心目标 |
|---|---|---|
| **Boss 直聘 / 猎聘首句打招呼** | 80 ～ 120 字 | 手机首屏 3 秒内抓住 HR/业务 Leader 眼球，换取“发份简历看看” |
| **脉脉 / 校友 / 同行内推私信** | 150 ～ 200 字 | 降低对方帮推心理负担，清晰给出岗位链接与 3 个硬核匹配点 |
| **LinkedIn 外联消息** | < 300 词 | 国际化专业沟通，建立同行/Recruiter 连接并阐述技术契合度 |
| **直投邮件（Cold Email）** | 150 ～ 250 字 | 作为简历附件的精炼导读，突出核心成果与求职诚意 |

## Inputs

Required:
- 目标公司名称和岗位方向
- profile datastore (`profile_store.yaml`)

Optional:
- 具体 JD 文件（有则精准提取痛点关键词）
- 目标渠道（`boss` / `referral` / `linkedin` / `email`，未指定时国内公司默认同时生成 `Boss直聘打招呼` + `内推私信`，外企默认生成 `LinkedIn 外联`）
- 收件人角色（业务团队 Leader / 同组工程师 / HR）

---

## Writing Rules by Channel

### 1. Boss 直聘 / 猎聘首句开场白（80 ～ 120 字）
- **去掉寒暄废话**：不要写“您好，我在 Boss 上看到贵司正在招聘……”。
- **三段式高密度结构**：`[学历/年限/核心定位] + [1-2 个最贴合 JD 的硬核项目或量化成果] + [礼貌请求发简历]`。
- **示例**：
  > 您好！我是墨尔本大学数据科学硕士，目前在小米负责 Launcher 客户端开发与稳定性治理（2 年经验）。深度做过 Perfetto 渲染链路调优、Hprof 内存泄漏治理及最近任务模块 Owner，并落地过基于 LLM + Playwright 的 Bug 自动分析流水线（排查耗时缩短 80%）。非常关注贵团队的客户端/AI 工程方向，不知是否方便发份简历供您评估？

### 2. 脉脉 / 校友 / 同行内推私信（150 ～ 200 字）
- **建立信任连接**：点明共同背景（如校友、同做 Android 系统层/AI 工程方向）并表达礼貌。
- **降低内推成本**：明确说明已看好具体岗位名称，并用 2–3 个短句概括“为什么我能过简历关”，让对方可以直接复制作为内推评语。
- **示例**：
  > 师兄/您好！在脉脉看到您在 [公司-部门]，冒昧打扰。我目前在看贵团队的 [岗位名称]，我是墨大硕士，目前在小米做桌面端核心模块开发与性能稳定性治理，同时独立开发了基于 LangGraph 的开源 AI 求职工程项目 OfferPilot。经历与贵部门要求的 [JD 核心方向] 非常契合。如果方便的话，想请教下组里目前还在招人吗？能否麻烦帮忙内推？简历已备好，非常感谢！

### 3. LinkedIn 外联消息（< 300 词）
- 开头提及对目标公司产品或近期技术动态的具体了解，不要泛泛而谈。
- 用 1–2 个具体项目经历说明与目标角色的相关性，保留真实量化数据。
- 语言匹配目标公司（国内团队用中文，外企/海外团队用英文）。

### 4. 直投邮件正文（Cold Email / 简历投递正文，150 ～ 250 字）
- 包含清晰的邮件标题格式：`应聘 [岗位名称] - [姓名] - [核心亮点/年限] - [学校]`。
- 正文采用 3 个要点列表概括核心匹配项，引导阅读附件 PDF 简历。

---

## Shared Constraints

- **100% 基于真实经历**：所有提及的公司、学校、技术栈和量化数字必须来自 `profile_store.yaml` 或原始简历，严禁为了迎合 JD 编造未做过的技术。
- **不卑不亢**：语气自信、专业、平实，不使用浮夸自吹词汇。

## Output

保存到 `outputs/misc/` 目录：
- 多渠道或国内打招呼：`outputs/misc/姓名_公司_打招呼.md`
- LinkedIn 外联：`outputs/misc/姓名_公司_LinkedIn外联消息.md`

## Error Recovery

- **profile_store 缺失**：外联消息必须基于真实经历，没有 profile 则不生成。提示用户提供 `profile_store.yaml` 或手动描述 1–2 个想突出的项目经历。
- **公司/岗位信息模糊**：根据已知信息生成通用版本，标注「信息有限」并建议用户补充具体 JD 后重新定制。
